# Confederate pension files for this tree's surnames

**Georgia Confederate Pension Applications are free and fully digitised** at the Georgia Archives Virtual
Vault, collection alias **`TestApps`** (supplements under `pension`). They are reachable by the same
CONTENTdm API and IIIF endpoints this project already uses for death certificates and county marriage film:

    dmQuery/TestApps/CISOSEARCHALL^<surname>^all^and/title!covera/title/800/0/1/0/0/0/json
    dmGetItemInfo/TestApps/<pointer>/json
    dmGetCompoundObjectInfo/TestApps/<pointer>/json
    https://vault.georgiaarchives.org/iiif/2/TestApps:<pagepointer>/full/1700,/0/default.jpg

The `covera` field carries the county, so a surname query can be filtered to the region in one pass.

**Widows' applications are the richer document.** A veteran's own application gives service, poverty and
occupation. A widow's gives all that *plus* a marriage date, a death date and a property schedule — which is
how Helen Wilson's file produced John M. Wilson's death date and their 1867 wedding.

Below: every pension file whose surname appears on this tree and whose county lies in the region it occupies
(Clinch, Coffee, Irwin, Berrien, Ware, Atkinson, Lowndes, Telfair, Appling, Pierce, Echols, Wilcox,
Montgomery, Bacon). **150 files. Three have been read so far** — Amanda Ricketson, Helen Wilson, and Thomas
Newbern, plus Sarah Yawn. The rest are unopened leads.
