# Portraits

Drop a photograph in this folder named for the person's id and it appears on
their card in the tree and at the top of their drawer. No code to change.

    docs/people/jack.jpg          John Wesley "Jack" Luke
    docs/people/nealie.jpg        Nealie Hinton
    docs/people/lucius.jpg        Lucius L. Luke
    docs/people/monroe.jpg        Monroe McKinnon Sr.

Square images work best — they are cropped to a circle. Anything from about
200x200 upward is plenty. Use `.jpg`.

A note on what belongs here: headstone photographs on Find a Grave belong to
the people who photographed them, so they are linked from the sources list
rather than copied into this folder. Family photographs you own are a
different matter entirely — those are yours to put here.
